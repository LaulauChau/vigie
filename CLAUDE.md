# Vigie

Weekly Slack digest of up to 5 picks on AI practice in dev and data, scored by a local Ollama LLM. Throwaway POC, run by hand.

Code, docs, issues, commits and PRs are written in English.

## Agent skills

### Issue tracker

GitHub Issues on LaulauChau/vigie, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
